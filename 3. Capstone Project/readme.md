## Personalized Specifications (K = 49)
- **Box Position & Size:** Starts at row `49` (screen address `16384 + 32 * 49 = 17952`), `20` rows tall, and `32` pixels wide (`2` words per row) from the left edge of the screen.
- **Assembler Feature (`49 mod 3 = 1`):** Validates instructions during assembly and prints `Line <n>: invalid instruction` instead of crashing on invalid syntax.

## Files Included
- `CPU.hdl` — Hack CPU implementation connecting the ALU, A/D registers, Program Counter, and instruction decoding logic.
- `Memory.hdl` — Hack data memory map combining RAM16K (`0–16383`), Screen (`16384–24575`), and Keyboard (`24576`).
- `Computer.hdl` — Top-level Hack computer integrating `ROM32K`, `CPU`, and `Memory`.
- `assembler.py` — Two-pass Hack assembler written in Python with symbol resolution and line-numbered error handling.
- `Box.asm` — Hack assembly program that draws the black box while a key is held down and clears it on release.
- `Box.hack` — 16-bit machine code generated by `assembler.py` from `Box.asm`.

## Implementation Summary

### Part A: Hack Computer Hardware
Implemented `Memory.hdl`, `CPU.hdl`, and `Computer.hdl` and verified them in the Nand to Tetris Web IDE against all five official test scripts (`Memory.tst`, `CPU.tst`, `ComputerAdd.tst`, `ComputerMax.tst`, and `ComputerRect.tst`).

### Part B: Two-Pass Python Assembler
`assembler.py` translates `.asm` source files into `.hack` binary files in two passes:
1. **Pass 1:** Strips comments and blank lines, tracks original source line numbers, and records `(LABEL)` declarations in the symbol table.
2. **Pass 2:** Converts A-instructions and C-instructions into 16-bit binary strings, allocates variables starting at RAM address `16`, and outputs `Line <n>: invalid instruction` if an unrecognized instruction is found.

Verified by comparing outputs against the official assembler on `Add.asm`, `Max.asm`, `Rect.asm`, and `Pong.asm`.

### Part C: Interactive Box Program
`Box.asm` continuously polls the keyboard memory register (`@KBD` / `24576`):
- When any key is pressed (`KBD != 0`), it writes `-1` (`1111111111111111`) across `2` consecutive 16-bit words per row for `20` rows starting at RAM address `17952`.
- When the key is released (`KBD == 0`), it writes `0` to the same addresses to clear the box from the screen.
